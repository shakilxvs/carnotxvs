# Carnot Universe

> Thermodynamics, visualised.

A clean, focused single-page React application with three interactive thermodynamics modules.

## Modules

- **Carnot Cycle** — Animated PV diagram with live piston cylinder, synchronized process visualization
- **Carnot Engine** — Schematic energy flow with animated heat arrows and flywheel
- **Math Module** — 4-tab calculator for solving any unknown in the Carnot cycle

## Tech Stack

- React + Vite
- Tailwind CSS
- Framer Motion
- Recharts
- Lucide React

## Run locally

```bash
npm install
npm run dev
```

## Deploy

```bash
npm run build
# Deploy /dist to Vercel
```
